## 🚀 About me

**Backend Software Engineer** working with **Python, Go and TypeScript**.
I build scalable, production-minded applications: APIs, cloud infrastructure,
and AI-assisted workflows that make real businesses run smoother, with a focus
on healthcare and lab tech.

- 🔭 Building healthcare and lab software, end to end
- 🌱 Exploring AI agents, MCP servers and voice/chat assistants
- ☁️ Deploying on AWS with Docker
- 💬 Ask me about backend design, APIs, and shipping to production
